# Security Policy

BookMCP is a local-first tool for books and documents the user has the right to process. It must not expose arbitrary filesystem reads, shell commands, mutation tools, or hosted AI uploads through MCP.

See [docs/SECURITY.md](docs/SECURITY.md) for the project security model and current limitations.

## Reporting A Vulnerability

Please report vulnerabilities through GitHub private vulnerability reporting if it is enabled for this repository. If it is not enabled, open a minimal public issue that avoids exploit details and request a private contact path.

Do not include copyrighted book text, private documents, secrets, or sensitive local paths in public reports.
