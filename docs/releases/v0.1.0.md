# BookMCP v0.1.0

Give Codex and Claude Code a searchable, citable library of your PDF books.

BookMCP ingests text-based PDFs into a local SQLite library and Tantivy BM25 index. Your MCP client can discover the library, search for a passage, fetch its context, and cite the title and PDF page. You can review and save a source-linked lesson through the CLI, then retrieve it in a later session.

[Watch the 45-second CLI/MCP demo](https://github.com/Prem5123/BookMCP/releases/download/v0.1.0/bookmcp-demo.mp4), recorded from real output with an original programming guide. The [source and transcript](https://github.com/Prem5123/BookMCP/tree/v0.1.0/docs/demo) are included.

## Try it

From the extracted folder, with `bookmcp` on your `PATH`:

```sh
bookmcp ingest tests/fixtures/tiny.pdf --book-id tiny-test --title "Tiny Test Book"
bookmcp search "citations" --book-id tiny-test
bookmcp doctor
```

Connect your agent:

```sh
codex mcp add bookmcp -- bookmcp serve
# Or:
claude mcp add --transport stdio --scope user bookmcp -- bookmcp serve
```

In a new agent session: “Use BookMCP to show my library. Search tiny-test for citations, read the matching chunk, and explain its advice with a page citation.”

## Included in this release

- Multi-book PDF ingestion, deterministic chunks, managed originals, and 1-based PDF page citations.
- Compact library discovery, keyword search, bounded context, read-only MCP tools/resources, and prompts.
- Explicit CLI lesson saves with source references and stale-source detection.
- Configuration helpers for Codex and Claude, integrity diagnostics, and index repair.
- Validation of IDs and retrieval limits, encrypted/scanned PDF errors, and cross-platform CI.

OCR, semantic/vector search, and automatic model memory are not implemented. MCP can draft and read lessons; saves happen explicitly through the CLI. BookMCP makes no hosted AI calls. Retrieved text enters the connected agent's context, so use a local model/client for an entirely offline assistant.
